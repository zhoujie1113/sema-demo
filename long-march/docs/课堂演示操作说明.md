# 《长征·征途》课堂演示操作说明

> 适用：中学历史课堂 / 45 分钟一课时  
> 预览：<http://127.0.0.1:8931/>  
> 说明：路线为示意图，非精确测绘；插画为 AI 手绘风格场景示意，不是历史照片。

## 一、课前 1 分钟准备

1. 在 Chrome / Edge 中打开预览地址。
2. 点击右上角“演示模式”。页面会切换为大字号全屏布局，并请求浏览器全屏。
3. 若浏览器未进入全屏，按 `F11`（macOS 可按 `Ctrl + Cmd + F`），或继续使用演示布局。
4. 投影检查：地图红线/地名是否清楚；若字号仍偏小，可用浏览器缩放 `Ctrl/Cmd + +`。
5. 建议先在总览页停留，让学生找到“于都”和“吴起镇”。

## 二、推荐演示流程（约 35 分钟）

### 1. 全程总览（5 分钟）

- 首页地图同时呈现五个阶段的路线与时间轴。
- 先让学生观察：**起点在哪、终点在哪、路线大致朝哪个方向、经过哪些省份**。
- 点地图上的阶段名称，或按 `→` 进入第一阶段。
- 可点“一键显示全程”随时回到完整路线。

### 2. 逐阶段推进（每阶段 5—7 分钟）

每个阶段按同一节奏操作：

1. 读左侧阶段卡：起止地点、时间、行进方向、阶段摘要。
2. 按 `空格` 或“逐步显示本阶段”，让路线按历史顺序延伸；路线上的红点同步显示当前地点与时间。
3. 路线走完后，点底部“关键节点”卡片，展开事件详情。
4. 读到“想一想”时暂停，先请学生回答，再按 `Esc` 关闭详情。
5. 按 `→` 进入下一阶段；按 `←` 返回上一阶段。

五个阶段与建议问题：

| 阶段 | 时间 | 建议追问 |
| --- | --- | --- |
| 01 突围西进 | 1934.10—12 | 湘江为什么损失惨重？地图上的渡口说明了什么？ |
| 02 转兵贵州 | 1934.12—1935.01 | 为什么放弃北上湘西？遵义会议“转折”转在哪里？ |
| 03 四渡赤水 | 1935.01—05 | 为什么要在赤水河两岸来回走？佯动有什么作用？ |
| 04 雪山草地 | 1935.05—09 | 大渡河、雪山、草地分别构成什么障碍？红军如何通过？ |
| 05 奠基陕北 | 1935.09—10 | 为什么把落脚点选在陕北？一份报纸起了什么作用？ |

### 3. 收束（5 分钟）

- 回到总览，按“一键显示全程”，让学生用一句话概括“时间—空间—转折”。
- 可打开“课堂说明”，展示史料来源与阶段划分依据。

## 三、演示控制

| 操作 | 作用 |
| --- | --- |
| `→` / `←` | 下一阶段 / 上一阶段（总览页按 `→` 进入第一阶段） |
| `空格` | 逐步显示 / 暂停 / 继续 |
| `R` | 重播当前阶段（总览页则重播全程） |
| `G` | 一键显示全程（立即显示五段路线） |
| `F` | 进入 / 退出全屏（演示布局内） |
| `Home` | 返回全程总览 |
| `Esc` | 关闭事件详情；再按一次退出演示模式 |
| 鼠标 | 点阶段路线、阶段名称、节点圆点、底部节点卡片均可进入 |

- “逐步显示”过程中，暂停后再次按 `空格` 从当前位置继续。
- 若切换浏览器标签页，动画会暂停；回到页面后继续。
- 动画只表示**行进顺序**，不代表真实行军速度，也不按真实距离比例播放。

## 四、常见问题

**Q：点击“演示模式”没有全屏？**  
浏览器可能阻止了全屏请求。页面已切换为演示布局，按 `F11` 即可；再按一次退出。

**Q：文字在投影上偏小？**  
演示模式已放大字号与地图标注；仍不够时用浏览器缩放（`Ctrl/Cmd + +`）。建议投影分辨率不低于 1280×720。

**Q：节点详情挡住了地图？**  
按 `Esc` 或点右上角“×”关闭；详情打开时仍可用 `← →` 切换阶段。

**Q：如何修改史实或地名？**  
编辑 `assets/js/data.js` 中对应阶段的 `route` 与 `nodes`，刷新即可。
