# 长征·征途

面向历史课堂的中文交互式网站。以**中央红军（红一方面军）1934 年 10 月—1935 年 10 月的长征**为主线，用一张可缩放的示意地图串起五个阶段、二十四个关键节点与教师演示模式。

- 预览地址（本地）：<http://127.0.0.1:8931/>
- 课堂操作说明：[docs/课堂演示操作说明.md](docs/课堂演示操作说明.md)
- 技术形态：原生 HTML / CSS / JavaScript，无构建步骤，直接静态托管即可。

## 功能

| 场景 | 内容 |
| --- | --- |
| 全程总览 | 完整路线、起点与终点、重要地点、行进方向、山脉河流、五阶段配色与等分时间轴 |
| 阶段路线 | 起止地点、时间范围、方向、阶段摘要、地形说明、3—5 个关键节点、迷你总览定位 |
| 节点详情 | 时间、地点、事件经过、面临的困难、历史意义、地形与路线选择、课堂思考题、来源链接 |
| 演示模式 | 全屏布局、大字号、← → 切换阶段、逐步显示路线、暂停/继续、重播、一键显示全程 |
| 键盘 | `←` `→` 阶段，`空格` 播放/暂停，`R` 重播，`F` 全屏，`G` 一键全程，`Home` 总览，`Esc` 关闭/退出 |

## 修改史实与路线

所有内容集中在 `assets/js/data.js`：

- `STAGES[].route`：该阶段的 `[经度, 纬度]` 途经点，地图自动平滑连线。
- `STAGES[].nodes[]`：节点名称、日期、地点、经过、困难、意义、地形、思考题与来源键。
- `STAGES[].labelAt`：阶段名称在地图上的落点。
- `OVERVIEW_LABELS`、`RIVERS`、`MOUNTAINS`、`PROVINCES`：总览地图的地名与山河示意。
- `SRC`：来源标题与链接。节点通过 `source` 字段引用。

修改后刷新页面即可；资源带版本号，若浏览器仍显示旧内容，可给 `index.html` 中的 `?v=` 换一个值。

## 阶段划分

本站为课堂教学把中央红军主线划分为五个阶段。**这是教学划分，不是唯一的历史分期。**

1. 突围西进：1934.10.10—12.01
2. 转兵贵州：1934.12.02—1935.01.17
3. 四渡赤水：1935.01.18—05.09
4. 雪山草地：1935.05.10—09.11
5. 奠基陕北：1935.09.12—10.19

长征是红军多支队伍的远征：红二十五军于 1934 年 11 月从河南罗山出发，1935 年 9 月到达陕北；红四方面军于 1935 年春强渡嘉陵江，开始长征；红二、红六军团于 1935 年 11 月从湖南桑植出发。1936 年 10 月，红军三大主力在甘肃会宁、宁夏西吉将台堡会师，长征胜利结束。

## 地图与插图说明

- 地图为**示意性历史地图**：地名按经纬度定位，路线依主要经过地点连线并作平滑处理；省界未绘，山脉、河流经过概括。**路线示意图，非精确测绘**，请勿用于距离测量或导航。
- 所有路线、地名、时间均为矢量与文本图层，可直接在 `data.js` 中编辑定位。
- 页面插画由图像生成工具制作，标注为“场景示意”，**不是历史照片**，不用于还原具体人物的相貌与服装细节。
- 路线播放动画只表示行进顺序，不代表真实行军速度或距离比例。
